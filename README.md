# 🌊 WaveOut — Open Source Android Speaker Cleaner

<p align="center">
  <b>Nettoyeur de haut-parleur & éjecteur d'eau pour Android — 100% Gratuit, Open Source & Sans Publicité.</b>
</p>

---

## ✨ Fonctionnalités

- 💧 **Water Eject** : Onde sinusoïdale pure 165 Hz avec vibrations continues pour expulser l'eau.
- 💨 **Dust Clean** : Balayage fréquentiel 300 Hz → 800 Hz pour déloger poussière et impuretés.
- 🧹 **Deep Clean** : Nettoyage multi-étapes (165 Hz → Balayage 200-2000 Hz → 440 Hz).
- 🎛️ **Mode Manuel** : Réglage personnalisé de la fréquence (20 Hz à 20 000 Hz) et de la durée.
- 📱 **Widget Écran d'Accueil** : Compatible MIUI / HyperOS, One UI, MagicOS, Pixel Launcher.
- 🌓 **Thème Sombre / Clair / Système** : Interface fluide Material 3.
- 🇫🇷 **Bilingue** : Français et Anglais intégrés.
- 📜 **Historique de sessions** : Sauvegarde des nettoyages effectués.

## 🛠️ Stack Technique

- **Langage** : Kotlin
- **UI** : Jetpack Compose & Material 3
- **Audio** : Android `AudioTrack` PCM 16-bit 44.1 kHz
- **Haptique** : `VibrationEffect` (API 26+)
- **Widget** : `AppWidgetProvider` & Foreground Service
